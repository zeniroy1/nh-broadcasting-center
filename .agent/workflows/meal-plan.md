# 주간 식단표 자동 처리

// turbo-all

## 사전 조건

- 식단표 폴더(`c:\Users\hamcoding\Desktop\codding\new folder\식단표\`)에 `본관.jpg`, `신관.jpg` 파일이 있어야 함

## 처리 순서

### 1단계: 폴더 생성 및 파일 이동

```bash
node process-menu.mjs --setup
```

- 이미지에서 날짜 범위를 입력받아 `식단표MM.DD_MM.DD` 폴더 생성
- 본관.jpg, 신관.jpg를 해당 폴더로 이동

### 2단계: 이미지 판독 및 HTML 생성

사진을 직접 보고 메뉴를 파악하여 HTML 파일을 생성합니다.

1. 생성된 폴더 내의 `신관.jpg`를 `view_file` 도구로 읽기
2. 메뉴 내용을 정확히 파악
3. 기존 HTML 템플릿(`주간메뉴표_신관_*.html`)과 동일한 형식으로 HTML 파일 생성
4. `본관.jpg`도 동일하게 처리
5. 사용자에게 생성된 HTML 파일 확인 요청 → 오타 수정

### 3단계: 캘린더 등록

```bash
node process-menu.mjs --calendar "식단표MM.DD_MM.DD"
```

- `menu-to-calendar.mjs`를 호출하여 Google Calendar에 등록

### 전체 자동 실행 (2단계 포함)

2단계 이미지 판독은 AI가 직접 수행하므로, 위 3단계를 순서대로 진행합니다.

## HTML 생성 규칙

### 신관 구조

- **아침**: 1행
- **점심 A코너**: 2행 (12:00~13:00, 1F~11F)
- **점심 B코너**: 3행 (11:30~12:30, 12F~20F)
- **샐러드바**: 4행

### 본관 구조

- **아침**: 1행
- **두레A**: 2행 (11:30~13:00)
- **두레B**: 3행 (12:00~소진시)
- **신토불이**: 4행
- **샐러드바**: 5행

### 특수 케이스

- `[행사]` 표시 → `event-text` 클래스 사용
- 공휴일 → `holiday-cell` 클래스, `rowspan` 적용
- 점심 소제목 (정월대보름, B코너 먹는날 등) → `section-title` 클래스
- B코너 빈칸 = A코너와 동일 메뉴 (시간만 다름)
