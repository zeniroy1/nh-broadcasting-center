💡 사용 방법

  • 제목 수정: 제목 클릭하여 직접 입력
  • 이동: 가구 드래그
  • 그리드 조절: 그리드 라인을 드래그하여 개별 간격 조정
  • 그리드 초기화: 조절한 그리드를 원래 상태로 복구
  • 영역 선택: 빈 공간에서 드래그하여 영역 내 객체 선택
  • 다중 선택: Ctrl 누른 상태에서 여러 객체 클릭
  • 다중 이동: 여러 객체 선택 후 드래그
  • 크기 조절: 선택 후 모서리 파란 점 드래그
  • 회전: 선택 후 위쪽 보라색 버튼 드래그
  • 글자 크기: 텍스트 선택 후 슬라이더 조절
  • 복제: 선택 후 '복제하기' 버튼 또는 Ctrl+D
  • 삭제: 선택 후 Delete 키 또는 삭제 버튼
  • 선 그리기: 시작점→끝점 클릭
  • 텍스트: 위치 클릭 후 입력, 더블클릭으로 수정
