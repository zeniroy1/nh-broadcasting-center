6단계 상품 상세 데이터 수집 설계

목록 후보의 product_id/product_url을 이용해 상세 페이지 공개 지표를 보강하는 스키마와 작업 청사진입니다.

검수 통과
23상세 필드 수
2추정 필드 수
5기본 상세 작업 수
35누적 자동 테스트

구현 흐름

Collection5단계 후보 작업에서 product_id와 product_url을 받습니다.
Detail Task우선순위 높은 후보부터 상세 페이지 작업을 생성합니다.
Direct가격, 브랜드, 리뷰 수처럼 공개 노출값을 보존합니다.
Refined성별, 시즌, 소재, 핏 문구를 표준 값으로 정제합니다.
Inferred무지 적합도와 40대 타겟 적합도에는 신뢰도와 한계를 붙입니다.

대표 상세 필드

필드 구분 소스 영역 신뢰도 규칙
product_name direct product_header 100% 상세 헤더의 상품명을 공백 정규화합니다.
sale_price direct price_area 100% 현재 노출 판매가를 원 단위 정수로 저장합니다.
material_keywords refined description_area 88% 소재 단어를 사전 기반으로 추출합니다.
plain_style_fit inferred name_description_image_alt 82% 무지, 로고, 프린트 단서를 조합하되 이미지 정밀 판정은 하지 않습니다.
age_40s_context_fit inferred category_description_review_summary 72% 실제 40대 구매자 수가 아니라 공개 문구 기반 타겟 추정입니다.

오픈형 설정

설정 파일

`src/config/collection_scope.json`에서 수집량, 우선순위, 정책 문구를 조정합니다.

검증 방식

기본 설정과 사용자 지정 설정 모두 테스트에서 수집량 변경 여부를 확인합니다.

경계 원칙

실제 구매자 수, 연령대별 구매 비율, 내부 랭킹 알고리즘은 수집 대상으로 표현하지 않습니다.

다음 단계는 리뷰 키워드 사전과 리뷰 기반 리스크 요약 규칙입니다. 사용자 승인 전까지 진행하지 않습니다.
