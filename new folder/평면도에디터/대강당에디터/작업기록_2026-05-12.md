# 대강당 평면도 에디터 작업 기록

작성일: 2026-05-12

## 대상 파일

- `대강당_평면도_에디터.html`

## 오늘 수정한 내용

### 1. 잠금 기능 보강

- 잠금 오브젝트가 실제로 편집되지 않도록 수정했다.
- 이동, 리사이즈, 회전, 삭제, 복제, 속성 변경, 그룹화, 레이어 이동에서 잠긴 오브젝트를 제외하도록 했다.
- 잠긴 오브젝트는 마우스 이벤트를 먹지 않도록 `pointer-events: none`을 적용했다.
- 이 수정으로 잠긴 무대연장 오브젝트가 아래/안쪽 오브젝트 선택을 막는 문제를 완화했다.
- 잠금/숨김 상태가 Undo/Redo 히스토리에도 보존되도록 했다.

주요 추가/변경 함수:

- `isLocked(el)`
- `isHidden(el)`
- `isEditable(el)`
- `updateLockClass(el)`
- `toggleLock()`
- `layerToggleLock(idx)`

### 2. 오브젝트 레이어 동작 보강

- 레이어 이동 시 기존 인라인 `z-index`가 DOM 순서 기반 레이어 동작을 방해하지 않도록 정리했다.
- `맨 위로`, `위로`, `아래로`, `맨 아래로` 동작이 DOM 순서 기준으로 작동하도록 보강했다.
- 잠긴 오브젝트는 레이어 이동 대상에서 제외했다.

주요 변경 함수:

- `clearInlineZIndex()`
- `topLevelObjects()`
- `bringToFront()`
- `layerMove(dir)`
- `layerMoveTop()`
- `layerMoveBottom()`

### 3. 오브젝트 및 속성 탭 표시 방식 변경

- 기존에는 오브젝트를 클릭해야 속성 패널이 보였다.
- 이제 `오브젝트 및 속성` 폴딩 탭을 열면 속성 영역이 항상 표시된다.
- 선택된 오브젝트가 없거나 잠긴 오브젝트가 선택된 경우, 속성 입력만 비활성화되도록 했다.

주요 변경 함수/CSS:

- `.prop-panel`
- `.prop-panel.is-disabled`
- `setPropControlsDisabled(disabled)`
- `syncPropPanel()`
- `updateSelectedProp(type, val)`

### 4. 패널 커스터마이징 기능 보강

- 기존에는 각 패널을 개별로 떼어 플로팅할 수 있었다.
- 오늘 수정으로 플로팅 패널끼리 다시 붙일 수 있게 했다.
- 분리된 패널 위에 다른 패널을 드롭하면 아래쪽에 붙는다.
- 붙어 있는 패널 묶음의 위쪽 패널을 이동하면 아래 붙은 패널도 같이 따라간다.
- 붙어 있는 묶음을 사이드바에 드롭하면 묶음이 같이 사이드바로 도킹된다.
- 드롭 대상 패널에는 하이라이트가 표시되도록 했다.

주요 추가/변경 함수/CSS:

- `.panel-dock-target`
- `.floating-panel.attached-panel`
- `clearDockHints()`
- `keepInViewport(x, y, width, height)`
- `clearFloatingPosition(panel)`
- `getAttachedFollowers(panel)`
- `moveFollowersBelow(panel, followers)`
- `dockToSidebar(panel, targetPanel, followers)`
- `floatPanel(panel, x, y, width)`
- `attachToFloatingPanel(panel, targetPanel)`

## 내일 확인하면 좋은 항목

- 실제 브라우저에서 잠금 오브젝트가 이동/삭제/속성변경되지 않는지 확인
- 잠긴 무대연장 위나 안쪽에 있는 다른 오브젝트가 클릭/수정 가능한지 확인
- 레이어 패널의 위/아래/맨위/맨아래 이동이 시각적으로 기대한 순서와 맞는지 확인
- `오브젝트 및 속성` 탭을 열었을 때 속성 영역이 항상 보이는지 확인
- 플로팅 패널끼리 붙이고, 붙은 묶음을 이동하고, 사이드바로 다시 붙이는 흐름 확인
- 패널이 화면 밖으로 나가거나 겹쳤을 때 사용성이 괜찮은지 확인
