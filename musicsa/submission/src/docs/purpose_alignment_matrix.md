# 목적 부합도 기록표

## 문서 목적

이 문서는 사용자와 Codex의 대화가 최종 목적에 얼마나 부합했는지 단계별로 기록한다.

최종 목적:

```text
무신사 공개 자료를 기반으로 상품을 검색/파싱하고,
공개 지표 기반 대체 지표를 만들어,
사용자가 원하는 제품에 빠르게 도달하도록 돕는 비교/추천 로드맵 프로그램을 설계한다.
```

## 부합도 기준

```text
95~100%: 최종 목적에 직접적으로 기여함
80~94%: 문제 정의나 요구사항 구체화에 강하게 기여함
60~79%: 제출 구조, 문서화, 작업 관리 등 간접적으로 기여함
30~59%: 보조적이지만 핵심 목적과는 거리가 있음
0~29%: 현재 목적과 거의 무관함
```
