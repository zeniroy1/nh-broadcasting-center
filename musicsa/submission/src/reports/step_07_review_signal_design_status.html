7단계 리뷰 기반 보조 지표 설계

리뷰 키워드를 실제 내부 통계로 단정하지 않고, 구매 판단을 돕는 보조 신호와 신뢰도 퍼센트로 정리합니다.

검수 통과
12리뷰 신호 카테고리
4리뷰 보조 지표
80%신뢰도 상한
35누적 자동 테스트

구현 흐름

Detail상세 후보의 product_id와 product_url을 입력 키로 사용합니다.
Review리뷰 영역 원문에서 공개 텍스트 단서만 봅니다.
Signal사이즈, 비침, 내구성, 원단, 핏, 재구매, 40대 타겟 신호로 분류합니다.
Metricscore, confidence_percent, evidence, limitation을 함께 산출합니다.
Next다음 단계에서 상세/리뷰 지표를 점수화 모델로 합칩니다.

내부 데이터 경계

반품률 아님

리뷰의 불만 키워드는 반품 리스크 단서일 뿐, 실제 반품률이 아닙니다.

재구매율 아님

재구매 언급은 만족도 단서일 뿐, 실제 재구매율이 아닙니다.

구매자 수 아님

40대/남편/출근 타겟은 실제 40대 구매자 수가 아닙니다.

다음 단계는 상세 지표와 리뷰 보조 지표를 결합하는 점수화 모델입니다. 사용자 승인 전까지 진행하지 않습니다.
