# NH 리마인더 — 설치 및 실행 가이드

## 1단계 | Flutter SDK 설치

1. https://docs.flutter.dev/get-started/install/windows 접속
2. **"Flutter SDK" 다운로드** (zip 파일, 약 1.5GB)
3. 압축 해제 위치: `C:\flutter` (경로에 한글·공백 금지)
4. **환경변수 PATH 추가**
   - Windows 검색 → "환경 변수 편집" → 시스템 변수 → Path → 새로 만들기
   - `C:\flutter\bin` 입력 후 확인

---

## 2단계 | Android Studio 설치

1. https://developer.android.com/studio 접속 → 다운로드 (약 1GB)
2. 설치 후 처음 실행 → SDK 자동 다운로드 (시간 소요)
3. **플러그인 설치**: File → Settings → Plugins
   - `Flutter` 검색 → 설치 (Dart 자동 포함)

---

## 3단계 | VS Code 확장 설치

VS Code에서 Extensions(Ctrl+Shift+X) → 검색:
- `Flutter` (Dart Code 팀) → Install
- `Dart` → Install

---

## 4단계 | Galaxy S23 USB 디버깅 활성화

갤럭시 S23에서:
1. **설정 → 휴대전화 정보 → 소프트웨어 정보**
2. **빌드 번호를 7번 연속 탭** → "개발자 모드 활성화" 메시지 확인
3. **설정 → 개발자 옵션 → USB 디버깅** 토글 ON
4. PC에 USB 연결 → 폰에서 "이 컴퓨터 허용?" → 허용

---

## 5단계 | flutter doctor 실행

VS Code 터미널(Ctrl+`) 또는 PowerShell에서:

```powershell
flutter doctor
```

모든 항목에 ✅가 표시되면 준비 완료.
❌가 있으면 표시된 안내에 따라 해결.

---

## 8단계 | APK 빌드 (배포용)

```powershell
flutter build apk --release
```

빌드된 APK 위치:
`D:\codding1\nh_reminder\build\app\outputs\flutter-apk\app-release.apk`

이 APK를 갤럭시에 전송 후 설치:
- USB 전송 또는 카카오톡 나에게 전송
- 폰에서 "출처를 알 수 없는 앱 설치 허용" 설정 후 설치

## 앱 최초 실행 시 권한 허용 목록

앱 실행 후 아래 권한을 **모두 허용**해야 정상 동작:

| 권한 | 선택 항목 |
|------|----------|
| 위치 | **항상 허용** (중요!) |
| 알림 | 허용 |
| 배터리 최적화 | 예외 등록 (최적화 안 함) |
| 사용 내역 접근 | 허용 (UsageStats — NH앱 자동 감지) |

> ⚠️ **위치 권한을 "앱 사용 중에만"으로 선택하면 백그라운드 감지가 안 됩니다.**
> 반드시 **"항상 허용"** 선택!

---

## 최초 설정 (현장 보정)

1. 앱 실행 후 **회사 근처(서대문역 5번 출구)**로 이동
2. 홈 화면의 **"현재 위치로 지오펜스 중심 설정"** 버튼 탭
3. 위도/경도가 갱신되면 정확한 위치로 지오펜스 등록 완료

---

## 문제 해결

| 증상 | 해결책 |
|------|--------|
| 알림이 안 울림 | 위치 권한 "항상 허용" 확인 |
| 앱 꺼지면 안 울림 | 배터리 최적화 → 예외 등록 확인 |
| 재부팅 후 안 울림 | 앱 한 번 실행하면 자동 재등록 |
| NH앱 감지 안 됨 | 설정 → 사용 내역 접근 → NH 리마인더 허용 |
