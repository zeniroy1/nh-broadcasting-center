# 1단계 구현 기록: 사용자 요청 해석 모듈

## 목표

사용자의 자연어 구매 요청을 무신사 검색/파싱에 사용할 수 있는 구조화된 조건으로 변환한다.

예시 입력:

```text
검은색 반팔 무지티를 2~3만원대에서 40대 남성이 입기 좋은 제품으로 찾아줘
```

예상 출력:

```text
상품군: 반팔 티셔츠
색상: 블랙
스타일: 무지
가격대: 20,000~30,000원
성별: 남성
연령대 힌트: 40대
검색어 후보: 블랙 무지 반팔 티셔츠 등
```

## 구현 파일

```text
src/scripts/musinsa_intent_parser.py
src/tests/test_musinsa_intent_parser.py
```

## 구현 범위

이번 단계에서는 네트워크 요청이나 무신사 실제 파싱을 수행하지 않는다.

구현한 기능:

```text
카테고리 감지
색상 감지
스타일 감지
가격대 감지
성별 감지
연령대 힌트 감지
필수 조건/선호 조건/제외 조건 분리
검색어 후보 생성
파싱 신뢰도 계산
CLI JSON 출력
```

## 대체 지표 원칙 반영

연령대는 실제 구매자 수가 아니라 공개 랭킹 필터 기반 대체 지표로만 사용해야 한다.

따라서 `age_band`가 감지되면 다음 안내를 결과에 포함한다.

```text
연령대는 실제 구매자 수가 아니라 공개 랭킹 필터 기반 대체 지표로 사용해야 합니다.
```
