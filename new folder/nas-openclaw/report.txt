2. 최종 docker-compose.yaml 설정
아래는 현재 정상 작동 중인 docker-compose.yaml 전체 내용입니다.
version: '3.8'
services:
  gateway:
    image: ghcr.io/openclaw/openclaw:latest
    container_name: openclaw-gateway
    ports:
      - "18789:18789"
      - "18790:18790"
    volumes:
      - /volume1/docker/openclaw/config:/home/node/.openclaw
      - /volume1/docker/openclaw/workspace:/home/node/.openclaw/workspace
    environment:
      - NODE_ENV=production
      - ANTHROPIC_API_KEY=[재발급 필요]
      - GEMINI_API_KEY=[재발급 필요]
      - OPENCLAW_GATEWAY_TOKEN=navm4unet!
      - OPENCLAW_GATEWAY_BIND=0.0.0.0
      - OPENCLAW__gateway__controlUi__dangerouslyAllowHostHeaderOriginFallback=true
    command: ["node", "dist/index.js", "gateway", "--bind", "lan", "--port", "18789", "--allow-unconfigured"]
    restart: unless-stopped
    init: true
3. openclaw.json 설정
경로: /volume1/docker/openclaw/config/openclaw.json
{
  "gateway": {
    "mode": "local",
    "bind": "lan",
    "controlUi": {
      "allowedOrigins": [
        "http://192.168.0.101:18789",
        "http://setec2.synology.me:18789",
        "http://127.0.0.1:18789",
        "http://localhost:18789"
      ],
      "dangerouslyAllowHostHeaderOriginFallback": true
    }
  }
}

5. 접속 방법
5-1. 내부 접속 (집 내부 네트워크)
http://192.168.0.101:18789/#token=navm4unet!
5-2. 외부 접속 (외부 네트워크/모바일)
http://setec2.synology.me:18789/#token=navm4unet!
⚠️ 주의: 외부 접속 시 크롬 브라우저에서 아래 설정 필요
크롬 주소창에 chrome://flags/#unsafely-treat-insecure-origin-as-secure 입력
입력란에 http://setec2.synology.me:18789 추가
Enabled 선택 후 Relaunch
