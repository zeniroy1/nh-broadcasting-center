# 다른 PC 첫 실행 안내

1. `LH_HUG_통합프로그램_설치.exe`를 실행합니다.
   - 설치 위치 선택 창에서 원하는 폴더를 선택합니다.
   - 예: `D:\LH_HUG_통합프로그램`
   - 취소하면 기본 위치에 설치됩니다.

2. 설치가 끝나면 CMD 창 없이 웹브라우저가 바로 열립니다.
   - 이후에는 바탕화면의 `LH_HUG_통합프로그램` 바로가기를 더블클릭합니다.
   - 숨김 실행용 VBS 원본은 설치 폴더 안에만 보관됩니다.
   - 첫 실행 중에는 웹브라우저에 환경 준비 상태가 표시됩니다.

3. Python 설치는 필요 없습니다.
   - 설치 파일 안에 portable Python 3.10이 포함되어 있습니다.
   - 프로그램은 설치 폴더 안의 `runtime/python/python.exe`를 사용합니다.

4. 첫 실행 시 자동으로 진행되는 작업
   - 필수 폴더 생성
     - `lh/outputs`
     - `hug/outputs`
     - `sh/outputs`
     - `gh/outputs`
     - `app/cache/hug`
   - 포함 Python에 필수 Python 패키지 설치
     - pandas, lxml, html5lib, beautifulsoup4

5. 주의사항
   - 첫 실행은 패키지 설치 때문에 인터넷 연결이 필요합니다.
   - 설치 완료 후 다음 실행부터는 설치를 건너뛰고 바로 실행됩니다.
   - 셋업 상태는 `app/config/setup_state.json`에 기록됩니다.

6. 산출물 위치
   - LH 결과: `lh/outputs`
   - HUG 결과: `hug/outputs`
   - SH 결과: `sh/outputs`
   - GH 결과: `gh/outputs`

7. LH 수집 기준
   - LH는 화면캡처/PNG 입력 없이 공고 페이지를 직접 크롤링합니다.
   - LH 탭에서 지역명을 추가하고 `공고 일정 확인`을 실행합니다.
   - 접수마감 공고는 목록에서 제외되고, 접수예정/접수중 공고만 후보로 표시됩니다.
   - 후보 공고를 선택한 뒤 `선택 공고 분석`을 실행합니다.
   - 현재 산출물은 기존 LH 보고서 로직과 같은 경쟁률 CSV/TXT 구조로 생성됩니다.
