8단계 점수화 모델 설계

리뷰 수를 구매 후 반응 누적 근거로, 리뷰 키워드를 구매자 타겟 추정 단서로 반영해 설명 가능한 final_score를 계산합니다.

구현 흐름

Proxy목적 적합도, 구매 신뢰도, 리뷰 기반 구매 반응 누적 근거를 받습니다.
Review리뷰 키워드 기반 리스크와 구매자 타겟 추정 단서를 보조 지표로 씁니다.
Public가격, 배송, 품절, 광고 여부처럼 공개 노출값을 반영합니다.
Weight`scoring_weights.json`의 가중치로 구성 점수를 합칩니다.
Outputfinal_score, confidence_percent, explanation, cautions를 만듭니다.

점수 경계

전환율 아님

`final_score`는 실제 구매 전환율이 아니라 공개 지표 기반 추천 계산값입니다.

구매자 수 아님

리뷰 수는 구매 후 반응 누적량의 공개 단서지만 실제 구매자 수나 판매량이 아닙니다.

속성 통계 아님

리뷰 키워드의 구매자 타겟은 실제 연령/성별별 구매 통계가 아닙니다.

다음 단계는 최종 후보 비교표와 추천 출력 템플릿입니다. 사용자 승인 전까지 진행하지 않습니다.
