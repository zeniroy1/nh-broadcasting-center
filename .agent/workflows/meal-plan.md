# 주간 식단표 자동 처리 워크플로우

// turbo-all

## 사전 조건

- 식단표 폴더(`c:\Users\hamcoding\Desktop\codding\new folder\식단표\`)에 **이번 주 식단표 이미지 파일들(`본관.jpg`, `신관.jpg`, `nh타워.jpg` 등)**이 존재해야 함.

## 처리 순서

### 1단계: 폴더 생성 및 파일 이동

```bash
node process-menu.mjs --setup
```

- 이미지에서 식단표 날짜 범위를 파악하여 입력 (예: `03.30_04.03` 등).
- `식단표MM.DD_MM.DD` 형식의 폴더가 생성됨.
- 감지된 이미지 파일(`본관.jpg`, `신관.jpg`, `NH타워.jpg` 등)이 자동으로 해당 폴더로 이동됨.

### 2단계: 이미지 판독 및 HTML 생성

AI가 직접 사진을 분석하여 메뉴를 파악하고 HTML 파일을 생성합니다. (가장 중요한 핵심 과정)

1. 생성된 서브 폴더 내의 각 이미지 파일(`신관.jpg`, `본관.jpg`, `nh타워.jpg`)을 확인.
2. 기존에 완성된 HTML 템플릿 코드 구조(예: `주간메뉴표_*.html`)를 참고하여 **동일한 형식으로** HTML 코드 작성.
   - ⚠️ **[매우 중요] 식사 시간(조식/중식/석식) 경계선 준수**
   - 표기의 `rowspan`과 가로선(특히 NH타워의 경우 노란색 경계선 등의 구분선)을 극명하게 살필 것.
   - 각 코너(A코너, B코너, 코너1~3, 두레A/B)가 어느 식사 시간(조식인지 중식인지 석식인지)에 속하는지 명확히 매핑하여 `<tr>` 및 `td.category` 구조를 짤 것.
3. 생성된 HTML 파일(`주간메뉴표_신관_YYYY_MM_DD.html` 등)을 폴더 위치에 맞춰 저장.
4. 사용자에게 생성된 식단표 파일 결과 및 행사 내역, 특이사항 반영 여부를 보고하고 피드백(오타나 범위 수정 요청)을 기다림. 
   - 사용자가 "여기는 식단이 없고 행사명만 들어가야 해" 등 부분 수정을 요청하면 HTML을 즉각 수정.

### 3단계: 캘린더 등록 (동기화)

사용자가 식단 HTML에 문제가 없음을 컨펌하거나 바로 진행하라고 한 경우 캘린더 등록을 수행합니다.

```bash
node process-menu.mjs --calendar "식단표MM.DD_MM.DD"
```

- `menu-to-calendar.mjs`가 백그라운드에서 실행되며 자동으로 Google Calendar에 이벤트를 동기화함.
- **[주의] 인증 만료 체크:** 만약 터미널 출력에 `🔗 아래 URL을 브라우저에서 열어 인증해주세요:`가 뜬다면, 캘린더 인증 토큰이 만료된 것이므로 사용자에게 해당 링크(URL)를 제공하고 클릭하여 로그인 연동을 해달라고 요청해야 함.
- 인증 완료 후 또는 기존 토큰으로 성공 시 `성공 5건 / 실패 0건` 등의 결과물이 터미널에 출력되며 완료됨.

## 🏗️ HTML 생성 규칙 및 구조 참고

### 신관 구조
- **아침**: 1행
- **점심 A코너**: 2행 (12:00~13:00, 1F~11F)
- **점심 B코너**: 3행 (11:30~12:30, 12F~20F)
- **샐러드바**: 4행

### 본관 구조
- **아침**: 1행
- **점심 (rowspan="2")** 하위에 **두레A** (2행), **두레B** (3행) 가 `sub-category` 로 구성될 수 있음.
- **신토불이**: 4행
- **샐러드바**: 5행

### NH타워 구조 (가장 복잡함 🔥)
- **조식 (rowspan="2")**: 코너2(한식), 코너3(스넥)
- **셀프라면 ZON (Café)**
- **중식 (rowspan="3")**: 코너1(일품), 코너2(한식), 코너3(분식)
- **플러스바**
- **테이크아웃 (Café)**
- **석식 (rowspan="2")**: 코너2, 셀프라면 ZON
- *주의: NH타워는 같은 '코너2'라는 이름이 조식, 중식, 석식에 모두 존재하므로 중식과 석식 메뉴가 섞이지 않도록 칸(경계 영역) 구분을 철저히 분석하여 병합(`rowspan`) 적용 필수!*

### 예외 및 특수 케이스 처리
- **행사 일자**: 식단 텍스트 대신 `event-text` 클래스 지정하여 `<행사>`, `행 사`, `휴무` 텍스트 등으로 기입.
- **공휴일**: `holiday-cell` 클래스 사용.
- **점심 소제목**: 정월대보름, 특식 먹는 날 등은 `span.section-title` 태그를 만들어 눈에 띄게 강조.
- **빈 코너**: 비어있거나 A코너와 메뉴가 같다고 표기된 부분은 그대로 구조만 유지.
